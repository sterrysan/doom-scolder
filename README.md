# 🛑 Doom Scolder

> **Your attention span called. It wants a restraining order.**

Doom Scolder is a ruthless, 100% local Chrome extension built to ruin your favorite desktop time-sinks (YouTube, Facebook, Instagram, Reddit, X/Twitter, TikTok, LinkedIn, Pinterest, Threads, Bluesky, Discord Web, plus custom domains).

---

## ⚡ Features

* **🌐 One Global Doom Pool:** Closing Reddit to open X doesn't reset your brain-rot allowance. One shared daily timer rules them all.
* **🎯 Surgical Route Scoping:** Blocks feeds by default while sparing YouTube `/watch` tutorials, Reddit `/comments/` debugging threads, and LinkedIn `/jobs`—unless you toggle **Full Site** like a masochist.
* **🔊 Audible Scolding + Momentum Traps:** Interval alerts plus instant screaming when you rapidly scroll feeds or swipe Shorts/Reels/TikToks. Bring your own MP3/WAV/OGG/M4A.
* **⚡ Dynamic Angry Icon & Sparks:** Toolbar icon shifts from calm olive → amber warning → short-circuiting crimson rage as your self-control dies.
* **🏎️ Asymmetric Shame Slalom:** Lowering limits is instant. Raising limits, disabling a site, or turning off Hardcore mode forces you through a thunderstorm laser-wire maze.
* **🧘 Midnight Reset + Hardcore Mode:** Auto-resets at midnight (unless you enable **Manual Reset Only**). Need an emergency unlock? Survive a 10-second timer and a one-strike leet-speak confession.
* **🔒 100% Offline & Private:** Zero servers, zero telemetry, zero snitching.

---

## 🚀 Local Install

1. Clone or download this repo.
2. Open `chrome://extensions/` and enable **Developer mode**.
3. Click **Load unpacked** and select this folder.
